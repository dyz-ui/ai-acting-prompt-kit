# 八维公式实操手册

> 这份文档是可以直接照着填的作业纸。所有规则来自 `docs/00-视频拆解.md` 拆出来的方法。

---

## 零、先记住三句话

1. **AI 看不见心理，只看得见证据。** 你要写的不是"她很羞愧"，是"羞愧在脸上留下的痕迹"。
2. **一次性给一个状态 = 表情包；给一条曲线 = 表演。** 任何情绪都要有 `A → B` 的转折。
3. **禁止项比形容词有用。** "眼泪暂时不能落下"这一句，比十个"悲伤"更管用。

---

## 一、三层结构：谁负责什么

| 层 | 负责 | 不负责 | 写多少字合适 |
| --- | --- | --- | --- |
| LAYER 01 全局控制 | 时长、画幅、年代、场景、人物长相、服装、声音、跨镜头一致性 | **不写情绪、不写表演** | 全文 20–30% |
| LAYER 02 镜头时间轴 | 分几个镜头、每个镜头几秒、机位、观察谁、何时切 | 不写具体表情 | 全文 10–15% |
| LAYER 03 表演控制 | 目的、情绪曲线、触发词、面部、目光身体、声音停顿、结束状态、禁止项 | — | 全文 **55–70%** |

一句判断标准：**如果一段话删掉之后，画面还是那个画面，那它就该在第三层；如果删掉之后人物会变脸，那它必须留在第一层。**

## 二、八维填空模板（每个节拍填一份）

复制这一段，把方括号里的内容换掉：

```
▸ 节拍{n}｜[起]–[止] 秒｜[谁]
  目的：[她此刻想要对方做什么／她自己在争取什么]
  情绪：[状态A] → [状态B]        ← 必须有箭头，不能只写一个词
  触发词："[台词里最关键的 2–5 个字]"
  台词："[完整台词，没有就删掉这行]"
  面部：[自然语言写 2–4 个可见动作]；辅助校准：AU__（强度）
  目光与身体：[看哪里／身体朝向／手在做什么／重心在哪]
  声音、呼吸与停顿：[音量／语速／哪个词重读／哪里破音／哪里没声音]
  停顿：[具体秒数 + 这段时间发生了什么]
  结束状态：[这个节拍结束的那一帧，她停在哪里]
  禁止：[不要提前出现什么／不要同时出现什么／不要做什么动作]
```

### 每一维的失败模式

| 维度 | 写坏了会怎样 | 自查问句 |
| --- | --- | --- |
| 时间段 | 模型把 20 秒的情绪平均摊开，全程一个表情 | 我有没有精确到 0.5 秒？ |
| 人物目的 | 情绪没有动机，观众觉得"她在无理取闹" | 她此刻**想要**什么？ |
| 情绪变化 | 愤怒和哭同时端上来，像表情包 | 我的箭头前后是两个不同状态吗？ |
| 台词触发词 | 表情挂在整段台词上，随机落在某个词 | 变化发生在**哪个词**上？ |
| 面部动作与AU | 甩一串编码，模型解析不了 | 我先写了人话，还是先写了编码？ |
| 目光和身体 | 人物只有脸在动，像贴图 | 她的眼睛在躲还是在钉？手在干什么？ |
| 声音呼吸停顿 | 一口气念完，没有气口 | 哪里**没有**声音？ |
| 结束状态与禁止 | 每段都演满，没有留白 | 我禁止了什么？ |

## 三、AU 速查（演戏常用 28 个）

**强度**：1 = A 极轻（刚可察觉）｜2 = B 轻（明显但克制）｜3 = C 中等（观众能读到）｜4 = D 强（情绪外溢边缘）｜5 = E 极强（接近面部极限）

**用法铁律**：`自然语言 → AU 校准`，顺序不能反。AU 是给模型的对齐锚点，不是给人看的密码。

| 编号 | 动作 | 英文 | 区域 | 读起来像 | 提示词写法 |
| --- | --- | --- | --- | --- | --- |
| AU1 | 眉毛内侧抬起 | Inner Brow Raiser | 眉 | 痛苦、担忧、恳求 | 眉毛内侧（眉心）缓慢向上抬起，眉形从平直变成八字 |
| AU2 | 眉毛外侧抬起 | Outer Brow Raiser | 眉 | 惊讶、疑问、注意 | 眉毛外侧抬高，额头出现横向浅纹 |
| AU4 | 眉毛下压 | Brow Lowerer | 眉 | 愤怒、专注、压迫 | 双眉向下压，眉心收拢，眉间出现竖向纹路 |
| AU5 | 上眼睑抬起 | Upper Lid Raiser | 眼 | 警觉、惊恐、瞪视 | 上眼睑抬高，露出比平时更多的眼白 |
| AU6 | 面颊抬起 | Cheek Raiser | 眼 | 真笑、眼部参与 | 眼下肌肉收紧，下眼睑下方鼓起，眼尾出现皱纹 |
| AU7 | 眼睑收紧 | Lid Tightener | 眼 | 隐忍、压抑、敌意 | 上下眼睑收紧，眼睛变窄，视线变硬 |
| AU9 | 鼻梁皱起 | Nose Wrinkler | 鼻 | 厌恶、轻蔑 | 鼻梁处向上皱起，鼻翼两侧出现短纹 |
| AU10 | 上唇抬起 | Upper Lip Raiser | 口 | 厌恶、不屑 | 上唇中部向上提起，露出上排牙齿边缘 |
| AU12 | 嘴角上扬 | Lip Corner Puller | 口 | 微笑、礼貌、勉强 | 嘴角向斜上方牵动，幅度克制 |
| AU14 | 嘴角收紧 | Dimpler | 口 | 克制、不认同 | 嘴角向内收紧，唇线变短，出现轻微酒窝 |
| AU15 | 嘴角向下 | Lip Corner Depressor | 口 | 悲伤、失望、无力 | 嘴角向下拉，下唇中部微微外翻 |
| AU16 | 下唇下压 | Lower Lip Depressor | 口 | 委屈、将哭未哭 | 下唇向下压并轻微外翻，下巴皮肤绷紧 |
| AU17 | 下巴抬起并绷紧 | Chin Raiser | 下颌 | 忍耐、把话咽回去 | 下巴向上抬起并绷紧，下唇被推起，喉部有吞咽动作 |
| AU20 | 嘴唇横向拉伸 | Lip Stretcher | 口 | 恐惧、紧张 | 嘴唇向两侧横向拉开，唇形变薄变宽 |
| AU23 | 嘴唇收紧 | Lip Tightener | 口 | 压抑怒火、克制 | 双唇向内收紧，唇色变浅，唇线绷直 |

| AU62 | 眼球向右 | Eyes Turn Right | 眼 | 回忆、寻找、逃避 | 眼球向右移动，眼睑跟随，头部不转 |
| AU64 | 眼球向下 | Eyes Down | 眼 | 羞愧、告解、放弃对视 | 眼球向下移动，上眼睑随之下垂 |

### 三阶段写法

任何 AU 都不要"第一帧拉满"，按 **起始 → 峰值 → 消退** 三段写：

```
错误：她眉毛下压，眼睛瞪大，很愤怒。
正确：前 0.6 秒眉毛逐渐下压到 AU4 的 3 级；说到"你"字时 AU25、AU26 突然增强到 4 级，形成一次短促爆发；
      最后一个词结束后 0.4 秒内快速减弱回 2 级——她要重新把失控压回去。
```

最后那半句"重新压回去"，就是表演和表情包的分界线。

## 四、四个可直接套用的情绪预设

### 1. 悲伤 · 将哭未哭

```
面部：眉毛内侧缓慢抬起，嘴角轻微下沉，下巴开始绷紧；张开嘴想继续说话，却没有立刻发出声音；眼眶逐渐湿润，但眼泪暂时不能落下
AU：AU1:3，AU15:2，AU17:2，AU7:2
禁止：不要在第一帧就流泪／不要皱眉成愤怒／不要低头躲避镜头
```

### 2. 愤怒 · 压住再爆

```
面部：说话前先压紧嘴唇、咬住下颚；眉毛向内下压；前半句保持低沉；说到刺激词时鼻翼张开，身体前倾；音量短促抬高；最后一个词结束后立刻闭嘴
AU：AU4:3，AU7:3，AU23:3，AU25:3，AU26:2
禁止：不要一开始就咆哮／不要瞪大眼睛／不要挥手
```

### 3. 压抑 · 把话咽回去

```
面部：下巴抬起并绷紧，双唇压紧，头部向下微低；喉部吞咽一次；呼吸从鼻子进出，肩膀不动
AU：AU17:3，AU24:2，AU54:2，AU7:2
禁止：不要摇头／不要后退／不要闭眼太久
```

### 4. 崩塌 · 情绪破防

```
面部：眉毛内侧高高抬起，眉心同时挤压；嘴角大幅下拉；张嘴吸气但发不出完整音节；眼睛短暂闭合又强行睁开
AU：AU1:4，AU4:2，AU15:4，AU26:3，AU43:2
禁止：不要一帧内完成／不要同时保持愤怒瞪视／不要用手遮脸
```

命令行也能直接取：

```bash
aiacting au --preset 悲伤
aiacting au --preset 愤怒
aiacting au --preset 压抑
aiacting au --preset 崩塌
```

## 五、30 秒四镜头的骨架

这是原视频验证过的节奏，可以直接套：

| 镜头 | 时长 | 功能 | 机位 | 表演密度 |
| --- | --- | --- | --- | --- |
| S1 | 0–3.7s | **建立**：交代距离和沉默，不说话 | 双人中景，固定 | 极低（只有呼吸） |
| S2 | 3.7–23s | **主戏**：拆 4–5 个情绪节拍 | 单人近景，极缓推 | 极高（每 3–5 秒一个转折） |
| S3 | 23–27s | **反应**：对方几乎不动，全在眼睛 | 对方近景，固定 | 低（一次抬眼看） |
| S4 | 27–30s | **落地**：回到开场机位，不解决问题 | 双人中景，固定 | 极低（静止） |

**为什么主戏要放在单人近景**：切换机位会打断情绪连续性。一条完整的曲线必须在一个不间断的镜头里跑完，观众才能看见"保护层失效"的过程。

**为什么 S4 要回到 S1 的机位**：构图重复 = 观众自己会做对比。开场两人相距一米，结尾还是那一米，中间发生的一切就被这"没变"的距离反衬出来了。

## 六、写完之后的五道自检

```bash
# 1. 结构体检（时间码、AU 合法性、缺项）
aiacting check my.yml

# 2. 编译出来通读一遍，看有没有你自己都想不出来的画面
aiacting build my.yml -o prompt.txt

# 3. 反向体检：把你以前写的提示词丢进去
aiacting lint old_prompt.txt

# 4. 生成后抽帧检查人物是否漂移
aiacting post contact output.mp4

# 5. 拼镜头、压音量、烧字幕
aiacting post concat shot1.mp4 shot2.mp4 -o final.mp4
aiacting post loud final.mp4
aiacting post sub final.mp4 subtitle.srt
```

自检问题清单：

- [ ] 每个节拍都有**箭头**（A → B），没有单一状态
- [ ] 每个有台词的节拍都标了**触发词**
- [ ] 每个节拍都有**禁止项**
- [ ] 面部描写里**没有一个纯情绪形容词**（体检会抓）
- [ ] 有至少一处写着**"没有声音"**或"停 X 秒"
- [ ] 最后一个节拍写了**结束状态**，而不是"然后她哭了"
