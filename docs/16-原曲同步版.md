# 原曲同步版 · 从 B 站取音轨并按歌声重排

> 用真实歌曲驱动画面节奏。抓取脚本思路在下面，音频本身不入库。

---

## 一、做了三件事

1. **从 B 站取到《老男孩》MV 的音轨**
2. **用语音识别拿到每句歌词的精确时间码**
3. **按这个时间码重排画面**——每句时长不再是固定的 4.6 秒，而是跟着歌声走

成片：`out/老男孩-原曲同步版.mp4`，51.9 秒，1920×1080 / 24fps。

---

## 二、抓取过程（三个坑）

### 坑 1：B 站搜索接口不带签名会被 412

旧的 `x/web-interface/search/type` 返回 HTML 拦截页，改用 **wbi 版**可以直接拿到 JSON：

```
https://api.bilibili.com/x/web-interface/wbi/search/type?search_type=video&keyword=老男孩
```

带 `User-Agent` 和 `Referer: https://www.bilibili.com` 即可。

### 坑 2：yt-dlp 走系统代理，B 站 CDN 被拦

本机 `https_proxy=http://127.0.0.1:63387`，下载 CDN 时报：

```
Tunnel connection failed: 502 Bad Gateway
```

解法：`yt-dlp --proxy ""`（强制直连）。

### 坑 3：整条音轨 3.5 MB，限速 50 KB/s

只要 50 秒，没必要下全片。用 `--download-sections` 让 ffmpeg 边下边切：

```bat
yt-dlp --proxy "" -f "30216/30232/bestaudio" ^
       --download-sections "*0:00-1:45" ^
       -o "out/bili/head.%(ext)s" ^
       "https://www.bilibili.com/video/BV15L4y1t7PE"
```

861 KB，几秒下完。

> 30216 = 64 kbps，30232 = 132 kbps。想要无损要登录 cookie，这次没做。

## 三、时间码从哪来

把音轨喂给语音识别，直接得到分段：

```
24.77  那是我日夜思念深深爱着的人啊。到底我该如何表达？
34.67  她会接受我吗？
37.77  也许永远都不会跟她说出那句话。
44.77  注定我要浪迹天涯，怎么能有牵挂？
51.02  梦想总是遥不可及，是不是应该放弃？
57.77  花开花落又是一季春天啊，你在哪里？
70.05  青春如同奔流的江河，一去不回，来不及道别……
```

按句子边界整理成七段（第 2 句横跨两个识别段，取 30.10 起；第 6 到第 7 句之间有空乐句，字幕提前在 64.35 收）：

```json
[[24.70, 30.10],
 [30.10, 37.55],
 [37.55, 44.70],
 [44.70, 50.95],
 [50.95, 57.70],
 [57.70, 70.05, 64.35],
 [70.05, 76.60]]
```

第三个数是"字幕结束时间"——画面继续，字幕先走，用来处理那句 12 秒的空乐句。

---

## 四、重排的实现

`scripts/lyric_sync.py` 复用 `lyric_layers` 的七个场景与图层机制，只改两处：

1. **时长按段给**，不是常量。图层延迟还要按 `dur/3.0` 等比压缩——短句不能让五层还没落完就切。
2. **音频按 `[24.70, 76.60]` 裁切**，与视频等长，最后 mux。

字幕出现时机：`最后图层落位 + 0.35s`，消失：`该句结束 - 0.30s`。
