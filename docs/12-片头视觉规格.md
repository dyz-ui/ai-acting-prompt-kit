# 历史课件片头 · 视觉规格与分镜

> 文体借自 [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar) 的 `STYLE.md`
> ——那份规格书最厉害的地方不是代码，是把"感觉"写成了可交接的规则。
> 这份文件对应实现：`scripts/manim_history_intro.py`

---

## 1. 本质，以及它不是什么

**一块刚被擦干净的板面，一个字一个记号地把自己写上去。讲完一件事就走，不炫技。**

- 它是**一块板**：纸板或黑板，有纹理、有边界、有一点点旧。
- 它是**一次讲授**：章节号 → 标题 → 时间跨度 → 印章落款，四件事，没有第五件。
- 它是**静止的**：除了一条时间轴在生长、印章落下，其余全部是淡入上浮，不做位移动画。

它**不是**这三种东西：

| 不是 | 区别在哪 |
| --- | --- |
| 不是"动态 PPT" | 没有色块滑入、没有 3D 翻转、没有粒子爆炸。PPT 的动效是给"页面切换"服务的，这里只有一个页面 |
| 不是"电影预告" | 不做快速剪辑、不做频闪、不加音效。片头的任务是让人安静下来，不是兴奋起来 |
| 不是"数据可视化" | 时间轴只是三个刻度，不承载信息量。它提供的是"时间感"，不是数据 |

---

## 2. 材质与渲染

- 全部矢量（Manim 的 Canvas 后端），**没有一张位图素材**，所以任意分辨率都锐利。
- 板面是纯色 + 一组极淡的横线（纸的稿线 / 黑板的擦痕）。横线透明度：纸版 0.16，黑板版 0.045。
- 光源不存在。没有投影、没有高光、没有暗角——平涂是这套视觉的底色。
- 唯一有"体积"的是印章：方块描边 + 6° 倾斜 + 0.08 的填色。

## 3. 配色逻辑（每种颜色只准干一件事）

### paper（默认）

| 色 | 值 | 只准用于 |
| --- | --- | --- |
| 纸 | `#EFE6D4` | 底 |
| 墨 | `#232120` | 主标题、副标题、时间轴线 |
| 锈红 | `#C1543A` | **章节号** 与 **印章**——两处，不多不少 |
| 淡墨 | `#8A8272` | 年份刻度 |

### chalk（黑板）

| 色 | 值 | 只准用于 |
| --- | --- | --- |
| 板 | `#1C2A25` | 深墨绿底 |
| 白粉笔 | `#F2EFE6` | 主副标题、轴线 |
| 橙粉笔 | `#E9A03C` | 章节号、印章框 |
| 淡粉笔 | `#8FA39A` | 年份 |

> **已知冲突**：锈红同时干了"章节号"和"印章"两件事。规格上应该分开——章节号用锈红，印章用更暗的红（或直接同墨色描边）。下一版改。

## 4. 字体

| 用途 | 字体 | 字号 | 规则 |
| --- | --- | --- | --- |
| 主标题 | 微软雅黑 Bold | 132 | 宽度超 7.4 单位等比缩 |
| 副标题 | 微软雅黑 Regular | 40 | 宽度超 8.2 缩 |
| 章节号 | 微软雅黑 Regular | 34 | 宽度超 5.6 缩，锈红 |
| 年份 | 微软雅黑 Regular | 26 | 不缩 |
| 印章 | 微软雅黑 Regular | 46 | 单字 |

中文不用衬线，是因为投在教室投影上宋体笔画太细，后排看不清。**课件的第一原则是后排可读，不是好看。**

## 5. 分镜（10 秒）

| 时间 | 画面 | 动作 | 缓动 |
| --- | --- | --- | --- |
| 0.00–1.15 | 空板 + 横线 | 时间轴从中心向两端生长 | ease_out_cubic |
| 1.15–2.00 | 时间轴 | 三个刻度 `GrowFromCenter`，年份自下淡入，错峰 0.25 | 线性 |
| 2.00–2.70 | 上部 | 「第一章」自下淡入上浮 0.2 | 线性 |
| 2.70–3.10 | 章节号左侧 | 锈红短杠从左画出（长度 0.38） | 线性 |
| 3.10–4.25 | 中央 | 主标题淡入 + 上浮 0.45 + 起始 1.06 倍缩放回正 | ease_out_cubic |
| 4.25–5.00 | 标题下方 | 副标题自下淡入 0.2 | 线性 |
| 5.00–5.55 | 右下 | 印章自上落下 0.5，缩放到 1.0 | ease_out_back |
| 5.55–9.15 | —— | 完全静止（**这是故意的**，给观众读完的时间） | —— |
| 9.15–9.85 | 全部 | 整体淡出 | 线性 |

**为什么中间空 3.6 秒**：片头是导入，不是正片。观众需要时间把"第几章、讲什么、哪个年代"读进脑子，然后你才开始讲。塞满动画的片头会让人来不及反应。

## 6. 两个变体怎么选

| 场景 | 用哪个 |
| --- | --- |
| 常规章节、讲义配套 | `paper`（纸感，安静） |
| 讲"起源""考据""文字演变" | `chalk`（黑板，有课堂在场感） |
| 投影仪偏暗的教室 | `paper`（浅底更亮） |
| 录屏/线上课 | `chalk`（深底在录屏里更稳，不刺眼） |

命令：

```powershell
.\scripts\make_intro.ps1 -Title 秦汉 -Sub "公元前 221 — 公元 220" -Style chalk
```

## 7. 常见错误（都是踩过的）

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 标题写太长不缩字号 | 溢出画面被裁 | 脚本已自动按 7.4 单位缩，但超过 8 字建议拆成主副标题 |
| 每个元素都加动效 | 像 PPT 模板 | 只有时间轴"生长"、印章"落下"是动效，其余是淡入 |
| 加音效 | 课堂里显得廉价 | 不加。需要声音时由讲者开口 |
| 时间轴刻度写满 | 信息过载 | 三个刻度足够表达"跨度"，多了就成图表了 |
| 印章太醒目 | 抢标题 | 印章永远在右下、永远比标题暗一档 |

## 8. 交接清单

换人做同一套片头，需要给的只有三样：

1. 这份文件
2. `scripts/manim_history_intro.py`
3. 一句命令：`.\scripts\make_intro.ps1 -Title X -Sub Y -Kicker Z`

除此之外不该有口头约定。
