# 命令手册

> 所有命令都在项目根目录执行。Windows 下用 `aiacting.cmd`，其它平台用 `./aiacting`。

---

## 0. 环境已就绪的检查

```bash
aiacting au --table          # 能打出 AU 表 = 依赖正常
ffmpeg -version              # 能打出 6.0 = 后期可用
git --version                # 2.5x
```

本机已安装的版本（部署时记录）：

| 组件 | 版本 | 用途 |
| --- | --- | --- |
| Python（venv） | 3.13.14 | 跑本工具 |
| PyYAML | 6.x | 解析 `*.yml` |
| edge-tts | 最新 | 免费中文配音 |
| yt-dlp | 2026.10.26 | 抓参考视频 |
| ffmpeg | 6.0 | 拼镜头 / 抽帧 / 烧字幕 / 压音量 |
| Playwright + Chromium | 最新 | 抓需要浏览器渲染的页面（可选） |

## 1. 查 AU

```bash
aiacting au AU7                 # 单个动作单元详情
aiacting au --table             # 28 个常用 AU 全表
aiacting au --preset 悲伤        # 按关键词模糊匹配预设
aiacting au --preset 愤怒
```

输出示例：

```
code    : AU7
cn      : 眼睑收紧
en      : Lid Tightener
region  : 眼
feel    : 隐忍、压抑、敌意
prompt  : 上下眼睑收紧，眼睛变窄，视线变硬
```

---

## 2. 建项目

```bash
aiacting new 我的戏             # 生成 我的戏.yml 骨架（含一场可直接跑的示例）
aiacting new 我的戏 -o proj/a.yml --force
```

骨架里已经填好一场 3.7 秒的样板，改 `shots.beats` 即可。

---

## 3. 体检

```bash
aiacting check my.yml
```

会抓这些：

- 时间码不连续、节拍超出镜头范围、节拍重叠
- AU 编号不存在、强度不在 1–5
- 节拍缺「人物目的」（AI 会自己编动机）
- 有台词但没标触发词
- 节拍没有禁止项
- 单个节拍超过 6 秒（模型控制力下降）
- 面部描写里出现裸情绪词
- AU4 与 AU1 同时高强度（复合情绪没标先后）

退出码 1 = 有 ERROR，可直接接进 CI。

---

## 4. 编译成提示词

```bash
aiacting build my.yml                       # 三层完整版（推荐）
aiacting build my.yml --flat                # 单段纯文本版（模型不吃结构时用）
aiacting build my.yml --layer 1             # 只出第一层，方便单独调场景
aiacting build my.yml -o prompt.txt         # 写文件
aiacting build my.yml --force               # 有 ERROR 也强行出
```

`--flat` 和完整版怎么选：

| 情况 | 用哪个 |
| --- | --- |
| 小云雀 / Seedance 2.5 | 完整版（它吃得下长结构） |
| 可灵、Vidu 等单段输入框 | `--flat` |
| 提示词超过平台字数限制 | `--flat`，再手动删第一层的风格描述 |

## 5. 给旧提示词做体检

```bash
aiacting lint old_prompt.txt
aiacting lint -t "女人非常悲伤地哭泣，眼泪止不住流下来。"
cat old.txt | aiacting lint
```

输出：

```
! 建议修（5）
   · 「女人非常悲伤地哭泣，眼泪止不住流下来」只给了情绪词（悲伤），没有可见动作，模型会自己编
   · 「女人非常悲伤地哭泣，眼泪止不住流下来」用了程度副词「非常」，模型无法量化，改成幅度或秒数
   · 全文没有禁止项（NO），模型会把情绪提前演满
   · 全文没有秒级时间码，无法控制节奏
```

## 6. 拆别人的片子

```bash
aiacting ingest https://v.douyin.com/xxxx/ -o reference
```

会做四件事：

1. 解析短链拿到真实 mp4 直链（先试 yt-dlp，失败则走公开解析接口兜底）
2. 下载到 `reference/video.mp4`
3. 抽音轨到 `reference/video.mp3`（16k 单声道，够转写用）
4. 每 8 秒抽一帧做拼图 `reference/video_sheet.jpg`，用来看机位和人物一致性

加 `--asr` 会顺带转写（需要先 `pip install faster-whisper`）：

```bash
aiacting ingest <url> --asr
```

> 抓片只用于自己研究结构，不要搬运别人的成片。

## 7. 配音

```bash
aiacting tts "我不知道我现在该拿它怎么办" -o line1.mp3
aiacting tts "I gave up the years." -o line2.mp3 --voice 男-低沉 --rate=-10%
```

可用音色：`女-温柔` `女-冷静` `男-低沉` `男-成熟` `男-旁白`，也可以直接填 edge-tts 的 voice id。

同时会生成同名 `.srt`，可以直接拿去烧字幕。

**什么时候需要它**：Seedance 的原声对白已经很强，但如果要改台词、换语言、或者平台不给原声，就用它配音，再走 `post` 合成。

## 8. 后期

```bash
# 拼多条生成结果（AI 片段编码常常不一致，默认重编码）
aiacting post concat shot1.mp4 shot2.mp4 shot3.mp4 -o final.mp4

# 抽帧检查人物有没有漂移（每 3 秒一帧，5 列拼图）
aiacting post contact final.mp4 --every 3

# 烧字幕（微软雅黑，白字黑边，靠下 42px）
aiacting post sub final.mp4 line1.srt

# 响度标准化到 -14 LUFS（短视频平台通用）
aiacting post loud final.mp4

# 看规格
aiacting post probe final.mp4
```

烧字幕用的是 `subtitles` 滤镜，Windows 路径里的盘符冒号会自动转义，不用手动处理。

## 9. 完整跑一遍（从零到成片）

```bash
# ① 建项目
aiacting new 我的戏

# ② 编辑 我的戏.yml（三层 + 八维，参考 examples/what-about-my-life.yml）

# ③ 体检 → 编译
aiacting check 我的戏.yml
aiacting build 我的戏.yml -o prompt.txt

# ④ 打开 小云雀 AI → Agent → 模型选 Seedance 2.5
#    时长 30 秒 / 横屏 / 开启原声 → 粘贴 prompt.txt 全文 → 提交

# ⑤ 下载成片后检查
aiacting post contact 我的戏.mp4
aiacting post loud 我的戏.mp4
```

## 10. 当成库用

```python
from aiacting import load, compile_text, AULibrary

proj = load("examples/what-about-my-life.yml")
print(compile_text(proj))            # 三层完整提示词

lib = AULibrary()
print(lib.describe("AU1:4"))         # 眉毛内侧抬起（AU1，D 强）
print(lib.natural_sentence(["AU1:4", "AU15:3"]))
```

也可以被别的脚本当模块调用，批量生成多个项目：

```python
from pathlib import Path
from aiacting import load, compile_text

for f in Path("projects").glob("*.yml"):
    Path(f.with_suffix(".prompt.txt")).write_text(compile_text(load(f)), encoding="utf-8")
```
