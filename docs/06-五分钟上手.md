# 五分钟上手

> 目标：从零到拿到一条能粘贴的提示词。全程不用写代码。

---

## 先记住三件事

1. **你写的不是情绪，是证据。** 不写"他很悲伤"，写"下巴绷紧、喉咙吞咽、眼泪停在眼眶里没有落下"。
2. **一次只演一个转折。** `A → B`，中间要有"撑不住"的过程。
3. **禁止项最值钱。** "眼泪暂时不能落下"这一句，比十个形容词都管用。

---

## 第 0 步：确认装好了（10 秒）

按 `Win + R`，输入 `cmd`，回车。然后敲：

```bat
aiacting au AU7
```

出这几行就对了：

```
code    : AU7
cn      : 眼睑收紧
```

> 如果提示"不是内部或外部命令"，说明 PATH 还没生效 —— 关掉这个窗口重新开一个。
> 如果中文是乱码，先敲 `chcp 65001`。

---

## 第 1 步：跑一个能用的样板（1 分钟）

```bat
cd /d C:\Users\LX\WorkBuddy\2026-10-30-18-10-06\ai-acting-prompt-kit
aiacting build examples\quickstart-10s.yml -o prompt.txt
```

打开 `prompt.txt`，你会看到三段：

```
【第一层 · 全局控制】    ← 片场：画幅、场景、人物长相、禁止项
【第二层 · 镜头时间轴】  ← 分几个镜头、几秒、机位看谁
【第三层 · 表演控制】    ← 真正的表演：目的、情绪曲线、触发词、AU、停顿
```

**这就是全部产物。** 复制它，粘到生成平台，出片。

---

## 第 2 步：改成你自己的戏（10 分钟）

打开 `examples\quickstart-10s.yml`（记事本 / VS Code 都行），只需要改这五处：

| 改哪里 | 改什么 | 例子 |
| --- | --- | --- |
| `project.location` | 戏发生在哪 | `深夜的出租屋厨房，只有灶台上方一盏暖黄小灯` |
| `project.lighting` | 光从哪来 | `单光源侧逆光，脸一半在暗处` |
| `characters` | 谁、多大、穿什么 | `34 岁 / 灰色旧 T 恤 / 胡茬` |
| `shots.beats[].objective` | 这个人此刻**想要**什么 | `不让对方听出自己已经崩了` |
| `shots.beats[].line` | 台词 | `……我知道了。` |

改完顺手做三件事：

- 每个节拍补一个 `trigger_line`（表情挂在哪个词上）
- 每个节拍补 `forbidden`（什么不许提前发生）
- 节拍时间加起来要等于镜头时长

---

## 第 3 步：体检（10 秒）

```bat
aiacting check examples\quickstart-10s.yml
```

它会替你抓这些毛病：

```
! 建议修（2）
   · 节拍 S1-B2 没有「禁止项」，AI 很容易提前把情绪演满
   · 节拍 S1-B1 长达 8.0s，建议再拆细，模型对长区间控制力下降
```

**看到 `✓ 体检通过` 再往下走。** 这一步省下的是抽卡钱。

---

## 第 4 步：编译 + 提交（5 分钟）

```bat
aiacting build examples\quickstart-10s.yml -o prompt.txt
```

然后：

1. 打开 **小云雀 AI**，进 **Agent** 模式（不是普通出图）
2. 模型偏好 → 视频 → **Seedance 2.5**
3. 时长 **30 秒**（或跟你的 `duration` 一致），画幅**横屏**
4. 打开**原生声音 / 原声**
5. 把 `prompt.txt` **整段**粘进去，一次提交

> 不要分段生成再拼 —— 分段会丢掉表演的连续性，正好毁掉你想控制的东西。

---

## 第 5 步：出片后检查（2 分钟）

```bat
aiacting post contact 你的片子.mp4 --every 3
```

会出一张缩略图拼图，重点看两件事：

- **人物有没有变脸**（跨镜头脸型、发型、衣服漂移）
- **情绪是不是被提前演满**（第一帧就很悲 = 禁止项没生效）

再看一眼节奏：

```bat
aiacting post probe 你的片子.mp4
```

不满意就回第 2 步改 YAML，**别在平台上反复抽卡**——抽卡是在赌，改 YAML 是在调。

---

## 常见卡点

**「我不知道该写多少个节拍」**
10 秒写 2 个，30 秒写 4–5 个。单个节拍超过 6 秒就该拆，体检会提示你。

**「AU 编号记不住」**
不用记全表。先写人话，再查：

```bat
aiacting au 眼睑收紧
aiacting au --preset 悲伤
```

**「我写的台词是中文，模型念得对吗」**
先跑一遍看口型。中英混排时把台词单独放一行，别塞进描述句里。

**「生成的画面人物一直在动，像在演话剧」**
在 `project.guardrail` 里加：`人物不做无动机的走动，身体重心保持在原地`。

**「出来的脸不像」**
30 秒内的人脸一致性靠"同一镜头不切"最稳。把主戏放在一个长镜头里跑完，别切机位。

---

## 三个千万别

1. **别一上来就写 30 秒。** 先 10 秒单镜头跑通，确认写法有效，再上四镜头。
2. **别在平台里改提示词。** 所有修改都回 YAML 改，然后重新 build —— 否则你改了什么自己都记不住。
3. **别删禁止项。** 那是整份提示词里性价比最高的部分。
