## 二、重装 / 换机器

```powershell
cd C:\Users\LX\WorkBuddy\2026-10-30-18-10-06\ai-acting-prompt-kit
powershell -ExecutionPolicy Bypass -File scripts\install_local.ps1
```

脚本是幂等的，跑几次都一样。它会：

1. 校验项目目录
2. 选一个**能创建 venv** 的 Python（自动跳过缺 `venvlauncher.exe` 的 3.11）
3. 建 `.venv`（已存在就跳过）
4. `pip install -e .`（可编辑安装，改源码立刻生效）
5. 在 `%USERPROFILE%\bin` 写入口，并确保该目录在 PATH

> 换机器时把桌面那个 zip 拷过去，解压后跑同一个脚本即可。

## 四、常见问题

### 1. 中文变乱码（`鐪肩潙鏀剁揣` 这种）

程序统一输出 UTF-8。老版 cmd 默认 GBK，所以先：

```bat
chcp 65001
```

PowerShell 里如果还乱，加一句：

```powershell
[Console]::OutputEncoding = [Text.Encoding]::UTF8
```

**不要**试图把程序改成输出 GBK——那会让 Git Bash、CI、重定向全部反过来出错。

### 2. 提示 `[aiacting] installation not found`

源码目录被移动或改名了。二选一：

- 把新路径改到 `C:\Users\LX\bin\aiacting.cmd` 里的 `AIACTING_HOME`
- 或者到新目录重跑 `scripts\install_local.ps1`

### 3. `python -m venv` 报 `Unable to copy ...venvwlauncher.exe`

你用的是本机那个装残了的 Python 3.11。脚本会自动跳过它；手动装的话指定 3.13：

```powershell
py -3.13 -m venv .venv
```

### 4. `pip install` 报 `Tunnel connection failed: 502`

网络/代理问题。换个时间重跑，或者用国内镜像：

```powershell
.venv\Scripts\python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pyyaml edge-tts yt-dlp
```

只有 PyYAML 是硬依赖，`edge-tts`（配音）和 `yt-dlp`（抓片）装不上不影响编译和体检。

### 5. 命令能跑但 `ingest` 拿不到抖音视频

抖音要新鲜 cookie，`yt-dlp` 走不通时程序会自动切到公开解析接口；再失败就换一条链接重试，或手动下载后用 `aiacting post contact <视频>` 抽帧。

## 五、关于那个 404

仓库本身是好的，已核实：

```
$ curl -o /dev/null -w "%{http_code}" https://api.github.com/repos/dyz-ui/ai-acting-prompt-kit
200
$ gh api repos/dyz-ui/ai-acting-prompt-kit --jq '.private, .visibility'
false
public
```

匿名访问也是 200，说明不是权限问题。国内容易出现的情况：

- `github.com` 直连不稳，浏览器拿到的是拦截页而不是真 404
- 用了公司/校园网，`github.com` 被 DNS 污染
- 剪贴板里的链接被加了不可见字符

**不影响使用**——源码在本机，命令在本机，离线包也在桌面。真要传给别人，用桌面那个 zip。
