# 课件导入开头 · 程序化视频方案选型

> 场景：给课件做一个 5–15 秒的**导入片头**，用代码生成，要有艺术感。
> 本机：i5-1135G7 / 16G / 无 GPU / Node 22.12 / Python 3.11 + Manim 0.22 / ffmpeg 9.0
> 检索时间 2026-10-30，星标为当时快照。

---

## 一、先说清这个场景的硬约束

| 约束 | 意味着什么 |
| --- | --- |
| 只有 5–15 秒 | 不需要"系统"，只需要"一个可复用的模板函数" |
| 每节课都要换标题 | 必须**参数化**：改一个字符串就能出新片 |
| 要有艺术感 | 排版、缓动、质感（颗粒/纸纹/描边）比"功能多"重要 |
| 本机无 GPU、要能反复渲 | 渲染必须纯 CPU、可离线、单条 1–2 分钟内 |
| 可能要一次做几十个 | 最好能命令行批量 + 模板化 |

**结论先行**：这不是"选一个万能框架"，而是"选一条技术路线"，因为四条路线的产物气质完全不同。

---

## 二、四条路线

| 路线 | 代表 | 气质 | 代价 |
| --- | --- | --- | --- |
| **A 浏览器渲染系** | Motion Canvas / Revideo / Remotion | 现代排版动效，能做到"发布会级别" | 依赖 Chromium，装入重，本机有坑 |
| **B 数学动画系** | Manim | 学术、矢量、图解感强 | 文字排版偏弱，非数学内容略"硬" |
| **C 2D 画布系** | skia-python / drawsvg / 自研 PIL | 完全可控，可做纸感/手绘/版画 | 每种效果都得自己写 |
| **D 白板手绘系** | srt-whiteboard-animation | 教学感、亲切、粉笔/马克笔 | 风格单一，不够"高级" |

## 四、三个可直接选的方案

### 方案 A · Motion Canvas（艺术上限最高）

**它是什么**：TypeScript 的"用代码画动画"框架，自带可视化编辑器，改代码画面实时变。专为"把一件事讲清楚"设计，正是课件开头的用途。

**做出来的样子**：标题从矢量线条里"长"出来，色块擦除转场，文字逐字上浮 + 轻微弹性，配一条细进度线。现代、干净、有设计感。

**代价**：
- 要装依赖（`npm create @motion-canvas@latest`），装包约 200–400 MB
- 导出走无头浏览器 —— **这台机器 remotion.software 解析失败过**，Motion Canvas 同样依赖 Chromium，需要先验证能否指向本机 Edge

**适合**：你打算做一整套、十几个片头，并且愿意花两三天摸熟。

---

### 方案 B · Manim（今天就能出片，零风险）

**它是什么**：3Blue1Brown 那套动画引擎，社区版已装好（0.22），本机有可用 demo。

**做出来的样子**：几何构图、线段生长、公式与图形变形。做"数据/结构/流程"的导入非常漂亮；做纯文字排版会偏"硬"，但用 `Text()` + 自定义缓动也能做文艺范。

**代价**：没有 LaTeX（本机未装），公式排版受限；中文要用 `Text(font="Microsoft YaHei")`。

**适合**：课件内容偏理科/结构图，或者你现在就想看到成片。

---

### 方案 C · 自研 skia / drawsvg 模板（最轻、最可控）

**它是什么**：接着我们已经写好的 `lyric_film.py` / `lyric_scenes.py` 往下做一层"片头模板"。skia-python 提供真正的矢量抗锯齿和渐变，drawsvg 则先生成 SVG 再栅格化。

**做出来的样子**：纸纹底 + 墨线描边 + 印章式落款，五分钟换一个标题就出一条。**我们上一版《老男孩》二维插画就是这个路线的产物**。

**代价**：每一种效果都要自己写（缓动、遮罩、粒子）。好处是——**没有黑盒，改一个像素都不用查文档**。

**适合**：你想要独一份的视觉语言，不想跟别人的模板撞脸。

---

### 方案 D · 白板手绘（教学气质，另开一路）

[srt-whiteboard-animation](https://github.com/geeklee/srt-whiteboard-animation) ★5.2k：暖米黄纸底，笔迹按字幕流式画出，mask 分区编排。纯 Python。

**做出来的样子**：像有人在你面前现场画板书，一笔一笔出来。亲切、有教学味。

**代价**：风格单一，做"高级感"不行，做"亲和力"很强。

---

## 五、我的建议

| 你的优先级 | 选 |
| --- | --- |
| **今天就要一条能用的片头** | **B（Manim）** —— 已装、零风险，2 小时能出第一版 |
| **要最好看、准备长期做** | **A（Motion Canvas）** —— 先花 1 小时验证 Chromium 能不能跑通 |
| **要有自己的视觉语言** | **C（自研 skia/drawsvg）** —— 我可以在现有代码上加"片头模板"层 |
| **要亲切的教学感** | **D（白板手绘）** |

**如果让我替你决定**：先走 **B 出一版**（今天就能看到效果、验证"艺术感"够不够），同时并行验证 **A 能不能跑**。如果 A 通得过，后面所有片头都迁到 A；如果通不过，就在 **C** 上继续加模板——反正 C 的底子（超采样、精灵、纸带版式）已经写好了。

不建议一上来装 Remotion：它能用，但许可证是自定义条款（公司规模超限要付费），做内部课件没问题，做成产品要看清条款。

## 六、装之前先做的一件事

npm 默认源在国内很慢，先换镜像：

```powershell
npm config set registry https://registry.npmmirror.com
```

pip 同理：

```powershell
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <包名>
```

这台机器实测下载速度约 500 KB/s，装 Motion Canvas 全套大概 10–15 分钟。
