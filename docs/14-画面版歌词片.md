## 三、五个制造"画面感"的手段

| 手段 | 怎么做 | 作用 |
| --- | --- | --- |
| **镜头推进** | 背景按 1.12 倍渲染，每帧裁一个缓慢平移的窗口（z 从 1.0 到 0.94，带横向摆动） | 静态图立刻"活"，这是最便宜的电影感 |
| **雾气** | 二维高斯衰减的云团（`exp(-(x²+y²))`），缓慢横移 | 分开天空与地面，制造空气透视 |
| **粒子** | 五种：雪 / 雨 / 浮尘 / 花瓣 / 星光，各自有深度（大小、速度、透明度随 z 变化） | 空间纵深 |
| **暗角 + 颗粒** | 径向压暗（中心 1.06 → 边缘 0.62）+ 高斯噪点 σ=3 | 去掉数码感 |
| **字幕压暗** | 底部 240px 的黑色渐变压暗（最高 43%） | 保证任何背景下字幕都可读 |

另外每句开头结尾各有 0.22 秒压黑，替代转场——**切场景不靠花哨特效，靠呼吸**。

## 四、加一个场景

```python
def sc_xxx(w, h):
    # 1. 背景：所有静态层画在 2 倍画布上，最后降采样
    def draw(d, W_, H_):
        d._image.paste(sky.resize((W_, H_)), (0, 0))
        d.polygon([...], fill=hexc("#111"))
        ...
    bg = build_bg(draw, w, h)

    # 2. 粒子：种类 / 数量 / 随机种子 / 区域 / 大小 / 速度 / 颜色
    particles = lambda t: Particles("snow", 46, 11, (0, 0, w, h * 0.7),
                                    (1.5, 4), (14, 40), (220, 226, 240))

    # 3. 返回 (背景, 粒子工厂, 边框色)
    return bg, particles, hexc("#0A0C16")
```

加进 `SCENES` 列表即可，超过 7 句会循环。

## 五、踩过的坑

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| 雾变成一条硬边横带 | 用叠椭圆做的，横向不变 | 改成二维高斯衰减，横竖都淡出 |
| 霓虹/月亮光晕是个方块 | 模糊被裁在图层边界 | 图层四周留 90px 空白再模糊 |
| 人影像保龄球瓶 | 圆头 + 梯形身体，比例失真 | 头用 0.95 倍宽的椭圆，肩 2.5 倍，腰收到 1.5 倍 |
| 花像一堆红点 | 花瓣太小且不重叠 | 花瓣直径放到 1.24 倍半径，六瓣重叠，中心加亮蕊 |
| 江面波光像条码 | 每行固定长度、均匀分布 | 只落在太阳正下方一条垂直带里，长度随机、行距递增 |
| 夜景死黑 | 纯线性输出，暗部全压到 0 | 输出前做 gamma 0.90 提亮暗部 |
| 字幕压在路面上看不清 | 背景亮度不可控 | 底部加 240px 渐变压暗 |

## 六、和纯文字版的区别

| | 纯文字版（`lyric_styles.py`） | 画面版（本脚本） |
| --- | --- | --- |
| 主体 | 文字是主角，画面是版式 | 画面是主角，文字是字幕 |
| 风格 | 五种平面设计风格轮换 | 七个叙事场景 |
| 节奏 | 3.2 秒一句，转场 0.75 秒 | 4.2 秒一句，压黑过渡 |
| 适合 | 观点输出、金句、口播配图 | 抒情、叙事、氛围向 |

两支片子用的是同一份歌词，可以对比着看哪种更贴你要的"洋气"。
