# 分层歌词片 · 图层生长 + 配乐

> `scripts/lyric_layers.py`
> 每个场景拆成 3–6 个图层，按顺序浮现（天 → 远山 → 近景 → 细节），最后落字幕。
> 配乐用 numpy 合成，不引任何外部音频素材。

---

## 一、跑一条

```bat
python scripts\lyric_layers.py 文本.txt 输出.mp4 --per 4.6 --fps 24
python scripts\lyric_layers.py 文本.txt --stills out\layers
python scripts\lyric_layers.py 文本.txt 输出.mp4 --no-audio    :: 只要画面
```

实测：1080p / 24fps / 33.2 秒，**222 秒渲完，13.4 MB**。

## 二、图层顺序（以"窗"为例）

| # | 图层 | 出现时刻 | 内容 |
| --- | --- | --- | --- |
| 1 | 天空 | 0.00s | 夜色渐变 + 月亮光晕 |
| 2 | 远屋顶 | 0.30s | 屋顶剪影（随机起伏） |
| 3 | 墙 | 0.55s | 暗墙 + 地面 |
| 4 | 窗 | 0.80s | 窗框 + 暖光 + 窗内人影 |
| 5 | 地面光 | 1.05s | 窗光洒在地上的梯形 |

每层淡入 0.75 秒，同时上浮 26px 归位。**五层落完约 1.8 秒**，然后字幕在 2.0 秒出现。

其余六个场景同理：公路是「天 → 远山 → 近山 → 路面 → 电杆与人」，花枝是「天光 → 枝 → 花 → 地面」，江面是「天 → 远岸 → 水面 → 波光」。

## 三、配乐怎么来的

全代码合成，五步：

1. **Pad 铺底**：Am–F–C–G 四和弦循环，每 4.2 秒一个，每个音加 ±0.4% 失谐做厚度，淡入淡出包络
2. **琶音**：每 0.7 秒一个和弦音（升八度），三个泛音叠加 + 指数衰减，模拟电钢琴
3. **混响**：四路延迟（0.13 / 0.21 / 0.34 / 0.55 秒）递减叠加，不引卷积库
4. **低通**：9 点滑动平均，削掉刺耳高频
5. **母带**：归一化到 -3 dBFS 峰值，首尾各 0.8 秒淡入淡出

实测响度：**平均 -17 dB，峰值 -3.1 dB**——刚好当背景，不抢字幕。

想换情绪，改 `chords` 那一行即可：大调换 `(261.63, 329.63, 392.00)` 就明亮，换更低的根音就沉。

## 四、加一个场景

```python
def sc_xxx():
    sky  = layer(lambda d, W_, H_: (...))   # 每层一个函数
    mid  = layer(lambda d, W_, H_: (...))
    near = layer(lambda d, W_, H_: (...))
    return [(sky, 0.00), (mid, 0.35), (near, 0.70)], \
           (lambda t: Particles("snow", 40, 7, (0, 0, W, H), (2, 5), (12, 30), (230, 230, 240))), \
           hexc("#0A0C16")   # 边框色
```

`layer()` 按 1920×1080 绘制并 2 倍超采样，返回透明底图层。

## 五、踩过的坑

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| 所有元素被放大 13% 且下移，字幕压在信封上 | 图层按"大画布"尺寸绘制，归一化坐标按 1216 算而不是 1080 | 图层按 1080 绘制，合成时贴到大画布的 `(PAD, PAD)` 处 |
| 太阳是个灰盘 | 亮色图层用 alpha 覆盖叠在亮背景上，只会变灰 | 改用**加色**（numpy 相加），亮背景上的光必须相加 |
| 图层烘进底图时跳一下 | 烘的时机和淡入位移未对齐 | 只在 `p ≥ 1`（位移归零）后烘 |
| 字幕和物体打架 | 各场景主体高度不同 | 主体统一收在 y < 0.86H，字幕固定在 H-148 |

## 六、三版对比

| | 文字版 `lyric_styles` | 画面版 `lyric_cinema` | **分层版 `lyric_layers`** |
| --- | --- | --- | --- |
| 主体 | 文字 | 画面 | 画面 + **可数的图层** |
| 出场 | 文字淡入 | 整幅切 | **一层层长出来** |
| 音频 | 无 | 无 | **合成配乐** |
| 渲染 | 40 秒 | 170 秒 | 222 秒 |

分层版慢，是因为每帧要做透明度合成；但它有"造世界"的观感——观众看到的是画面被一笔笔画出来，而不是切过去。

## 七、还能往哪走

- **配乐跟画面联动**：每层落位时给一个轻音（现在只有铺底），最省事的做法是在 `delays` 处插入一个短促的铃声
- **图层反向退场**：句尾把近景退回，留天空接下一句，比压黑更顺
- **视差**：让不同图层用不同的镜头推进速度（远景慢、近景快），depth 会更真
