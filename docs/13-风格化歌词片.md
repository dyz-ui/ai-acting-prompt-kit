# 风格化歌词片 · 多风格 × 多转场

> `scripts/lyric_styles.py`
> 每句换一种视觉风格，句与句之间用不同转场连接。纯代码绘制，无 AI 模型。

---

## 一、跑一条

```bat
python scripts\lyric_styles.py 文本.txt 输出.mp4 --per 3.2 --trans 0.75
python scripts\lyric_styles.py 文本.txt --stills out\styles     :: 只出静帧先看
```

实测：1080p / 24fps / 7 句 22.4 秒，**40 秒渲完，6.6 MB**。

## 二、五种风格

| # | 名字 | 视觉 | 适合的歌词气质 |
| --- | --- | --- | --- |
| 1 | 瑞士网格 | 米白网格 + 黑体大字 + 一个橙方块 | 冷静、克制、宣言感 |
| 2 | 孔版双色 | 宋体 + 蓝橙错位套印 + 米黄网点纸 | 怀旧、印刷物、旧唱片 |
| 3 | 霓虹 | 近黑底 + 青字 + 实时光晕 | 夜、城市、孤独 |
| 4 | 蓝图 | 深蓝底 + 白网格 + 四角标记 | 理性、工程、回望 |
| 5 | 半调 | 白底渐变网点 + 黑字 + 橙横条 | 波普、报纸、青春 |

七句会循环到第 1、2 种，所以头尾风格呼应——这是有意的，不是 bug。

## 三、三种转场

| 转场 | 形态 | 用在哪 |
| --- | --- | --- |
| 交叉溶解 | 整屏均匀过渡 | 情绪相近的两句 |
| 横向擦除 | 一条竖直边界从左推到右（40px 柔边） | 风格差异大、需要"翻页"感时 |
| 上下推入 | 上半先走、下半后跟 | 需要节奏感时 |

按 `(句子序号) % 3` 轮换。

---

## 四、关键设计决定：转场只作用于背景

第一版让文字跟着遮罩一起被"擦"过去，结果两个字：

- 擦除到一半时，文字被切成半截，像渲染错误
- 圆形转场时，字被圆边缘裁断

**改成：遮罩只混合背景，文字独立淡入淡出。** 文字永远不会被切，转场仍然有气势。

代价是转场中段会有约 0.35 秒"无字"的空档——这反而是对的，换页需要呼吸。

## 五、加一种新风格

写一个函数，返回固定结构即可：

```python
def style_xxx(text: str):
    bg = build_bg(lambda d, w, h: (...))          # 静态背景，2x 超采样
    f = to_font_size_for(text, F_HEI, 128, W*0.85) # 自动缩字号
    rgb, a = text_layer(text, f, INK, spacing=6)   # 文字层
    return bg, rgb, a, x, y, "风格名"               # 可选第 7 项：辉光层
```

辉光层格式：`(rgb, alpha, dx, dy)`——用于霓虹这类需要发光的效果。

然后加进 `STYLES` 列表，它会自动进入轮换。

## 六、踩过的坑

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| 孔版双色缩略图发紫 | 蓝橙两层各 50% 混色 | 蓝做主体、橙错位叠印（alpha 0.72，偏移 13,10） |
| 霓虹字后面有个方块 | 辉光层没留余量，模糊被裁在 bbox 边界 | alpha 四周加 90px 空白再模糊 |
| 转场中两层文字叠在一起 | 上一句文字没退场 | 文字结尾 0.45s 淡出，转场时只混背景 |
| 擦除边界出现两条竖线 | 遮罩用广播计算，形状对不齐 | 改用显式切片，硬边界 + 40px 线性斜坡 |

## 七、和那四个 Opus 项目的关系

- **借了 `lemo-opuscar` 的分类法**：它用 `styles/<slug>/STYLE.md` 的方式把风格做成可交接的规格，这份脚本沿用了同样的思路（一种风格 = 一个函数 + 一段视觉定义）。
- **借了 `pdoom-video` 的转场思路**：转场是"页与页之间"的事，不是"元素进场"的事。
- **没搬任何代码**：他们跑 TypeScript + Canvas/WebGL，我们跑 Python + PIL，产物目标一致，实现路径不同。

想扩展时，去看 `lemo-opuscar/styles/` 里对应的 STYLE.md，把"配色职责、材质、动效"三条读一遍，再写函数——比凭空想快得多。
