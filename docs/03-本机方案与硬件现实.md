# 本机方案与硬件现实

> 这份文档解释：为什么本机只做"控制"，不做"生成"，以及三条路线的真实代价。

## 二、结论：这台机器不能本地生成

必须把这句话说清楚，否则你会花两天装环境然后发现跑不动。

| 开源方案 | 参数量 | 官方最低显存 | 本机 2 GB 能否跑 |
| --- | --- | --- | --- |
| Wan2.2 / Wan-Animate-2 | 14B | 24 GB（fp16）／ 8 GB（量化后勉强） | ❌ |
| HunyuanVideo-Avatar | 13B | 24 GB 起 | ❌ |
| InfiniteTalk | 14B 底座 | 16–24 GB | ❌ |
| LivePortrait（只驱动表情） | 小模型 | 4–6 GB | ❌ |
| Stable Diffusion 1.5（只出单帧） | 0.9B | 4 GB | ⚠️ 极慢，7 分钟出一张 |

再算一笔时间账：30 秒 1080p 视频 = 900 帧。即便用最省的方案，在 MX450 上也是**以天为单位**，而且 2 GB 显存连模型权重都放不下，会直接 OOM。

**所以：生成必须放到云端。** 这不是妥协，是这类任务的正常工程选择——原视频作者自己也是用云端（小云雀 + Seedance 2.5），没有本地跑模型。

## 三、正确的分工

```
┌─────────────────────────────┐        ┌──────────────────────────┐
│        本机（CPU 足够）       │        │      云端（必须）          │
│                             │        │                          │
│  · 剧本 / 分镜 / 节拍设计      │        │  · Seedance 2.5 出片      │
│  · 八维提示词编译（本仓库）    │  ───▶  │  · 30 秒 + 原生对白        │
│  · 提示词体检（lint）         │        │  · 精确时间戳控制          │
│  · 抽帧质检（人物是否漂移）    │  ◀───  │                          │
│  · 拼接 / 压音量 / 烧字幕     │        │  可选：租 GPU 跑开源模型    │
│  · 免费配音（edge-tts）       │        │  （Wan-Animate / InfiniteTalk）│
└─────────────────────────────┘        └──────────────────────────┘
```

本机能做的四件事，恰好是**决定成片质量的那四件**：写对提示词、发现人物漂移、把片子接起来、把声音做干净。生成只是其中一环。

## 四、三条路线，按代价排序

### 路线 A · 纯云端（推荐，本机零额外成本）

直接用原视频验证过的组合：**小云雀 AI（Agent）+ Seedance 2.5**。

- 成本：按积分计，作者口径是一条 30 秒约 700 积分
- 本机负担：零
- 门槛：提示词写得好不好，就是本仓库解决的问题
- 适合：现在就要出片

### 路线 B · 租 GPU 跑开源（可控性最高）

想改模型、想跑 Wan-Animate-2 做"表演迁移"（把真人表演搬到 AI 角色上），就得租卡。

- 显存要求：24 GB 起（A10 / 4090 / L20 这一档）
- 成本：按小时计费，用完就停；比自己买卡便宜两个数量级
- 本机负担：只需要 SSH + 浏览器
- 适合：要做系列化、要固定角色、要批量

仓库里已经准备好脚本骨架：`scripts/remote_gpu_setup.sh`（在租来的机器上跑，不要在本地跑）。

### 路线 C · 换机器（不建议为了这个换）

要本地跑，需要 24 GB 显存 + 64 GB 内存 + 至少 100 GB 空闲磁盘。为一条 30 秒短片不值得，除非你要长期做。

## 五、本机已经装好什么

| 组件 | 位置 | 说明 |
| --- | --- | --- |
| Python venv | `.venv/`（Python 3.13.14） | 独立环境，不污染系统 Python |
| PyYAML | venv | 解析项目 YAML |
| edge-tts | venv | 免费中文配音 + 自动生成 srt |
| yt-dlp | venv | 抓参考视频 |
| ffmpeg 6.0 | 系统 PATH | 已有，未改动 |
| Playwright + Chromium | 全局 | 抓需要浏览器渲染的页面（可选） |

**故意没装的**（以及原因）：

- `torch` / `diffusers` / `comfyui` —— 2 GB 显存跑不动，装了只占 3–5 GB 磁盘
- `faster-whisper` —— 可选，需要本地转写时再装（`pip install faster-whisper`，纯 CPU 可用，7 分钟音频约 3–6 分钟）
